Data integrity and limitations

CreatorPilot V2 does not claim live YouTube access or AI model inference. It uses transparent local calculations and text templates, which you can review. A linked channel URL alone is not enough to fetch metrics on GitHub Pages.
How are metrics calculated?

View index = video views ÷ median views across supplied videos. Engagement per 100 views = 100 × (likes + comments) ÷ views. Missing interactions are treated as zero if the field is blank; do not compare with channels whose data is incomplete. For more meaningful comparisons, analyze uploads of similar ages and formats.
